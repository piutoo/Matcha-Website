
# The Matcha Page 🍵

An educational website exploring matcha, including
its history, varieties, benefits and preparation.

## Live Website
[View The Matcha Page](https://piutoo.github.io/Matcha-Website/)

## Technologies Used
- HTML
- CSS
- JavaScript
- Figma

## About the Project
I created this website because of my personal
interest in matcha and wanted to make learning
about it more accessible and engaging.

The website was first designed in Figma before
being developed using HTML, CSS and JavaScript.

## Features
- Educational pages about matcha
- Interactive navigation
- Images and visual content
- Consistent layouts and colour scheme
